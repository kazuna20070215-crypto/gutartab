# TAB GENIE SOCIAL ビジネス要件定義書 (Ver. 1.0)

## 1. プロジェクトの背景と目的

### 1.1. 背景
ギターやベースなどの楽器を練習する際、TAB譜（タブ譜）は欠かせない存在である。しかし、既存のTAB譜サービスには以下の課題がある：

- 無料で質の高いTAB譜を見つけるのが困難
- TAB譜を作成・共有するプラットフォームが分散している
- 練習の記録や進捗を管理する機能がない
- 同じ曲を練習している仲間と繋がる手段がない

### 1.2. 目的
本プロジェクトの目的は、**TAB譜の作成・共有・練習を一つのプラットフォームで完結**できるソーシャルサービスを提供することである。

AIによるTAB譜自動生成機能を搭載し、初心者から上級者まで、すべてのギタリスト・ベーシストの練習をサポートする。

## 2. ビジネスゴール

* **ゴール1 (共有):** ユーザーが作成したTAB譜を簡単に共有し、コミュニティで活用できる環境を構築する
* **ゴール2 (AI支援):** AIによるTAB譜自動生成で、TAB譜作成のハードルを下げる
* **ゴール3 (継続):** 練習ログ機能により、ユーザーのモチベーション維持と継続的な練習を支援する
* **ゴール4 (繋がり):** 同じ曲や同じジャンルを練習するユーザー同士の交流を促進する

## 3. ターゲットユーザー

| ペルソナ | 特徴 | 求めること (要求) |
| :--- | :--- | :--- |
| **初心者ギタリスト** | ギターを始めたばかり。簡単な曲から練習したい。 | 難易度別のTAB譜、練習のコツ、モチベーション維持 |
| **中級者プレイヤー** | ある程度弾ける。好きな曲を完コピしたい。 | 高品質なTAB譜、練習記録、上達の実感 |
| **TAB譜クリエイター** | 自分で耳コピしてTAB譜を作成できる。 | 作品の公開場所、フィードバック、承認欲求 |
| **バンドマン** | バンドで演奏する曲のTAB譜が必要。 | 正確なTAB譜、パート別表示、共有機能 |

## 4. 主要なビジネス要件（スコープ）

### 4.1. 必須要件 (Must Have) - MVP

* **要件1: TAB譜の閲覧・検索**
    * 曲名、アーティスト名、難易度、ジャンルでTAB譜を検索できる
    * TAB譜を見やすく表示する

* **要件2: TAB譜の作成・投稿**
    * ユーザーがTAB譜を作成して投稿できる
    * 基本的なTAB譜エディタを提供する

* **要件3: AI TAB生成**
    * 曲名やコード進行を入力するとAIがTAB譜を自動生成する
    * 生成されたTAB譜を編集・保存できる

* **要件4: 練習ログ**
    * 練習した曲、時間、感想を記録できる
    * タイムラインで練習ログを共有できる

* **要件5: ソーシャル機能**
    * ユーザーをフォローできる
    * TAB譜や練習ログにいいね・コメントできる
    * ユーザープロフィールページ

* **要件6: ユーザー認証**
    * メールアドレス/ソーシャルログインでアカウント作成
    * プロフィール編集

### 4.2. 将来要件 (Should Have) - Phase 2以降

* TAB譜の再生機能（音声プレビュー）
* 難易度自動判定
* 練習統計ダッシュボード
* バンド/グループ機能
* プレミアムプラン（広告非表示、高度なAI機能）

### 4.3. やらないこと (Won't Have)

* 楽譜（五線譜）の表示・作成
* 動画レッスン機能
* 楽器販売・EC機能
* ライブ配信機能

## 6. 画面構成

### 6.1. 主要画面一覧

1. **ホーム（タイムライン）** - フォロー中ユーザーの投稿を表示
2. **探索** - トレンドTAB、新着TAB、おすすめユーザー
3. **TAB詳細** - TAB譜の表示、いいね、コメント
4. **TAB作成** - 手動作成 or AI生成
5. **ライブラリ** - 保存したTAB、作成したTAB
6. **プロフィール** - ユーザー情報、投稿一覧
7. **ダッシュボード** - 練習統計、アクティビティ
8. **設定** - アカウント設定、通知設定

## 7. データモデル

### 7.1. 主要エンティティ

```
User（ユーザー）
├── id, username, display_name, avatar_url, bio
├── created_at, updated_at

Tab（TAB譜）
├── id, title, artist, content, difficulty, genre
├── user_id (作成者), is_ai_generated
├── likes_count, saves_count
├── created_at, updated_at

PracticeLog（練習ログ）
├── id, user_id, tab_id
├── duration_minutes, content
├── created_at

Like（いいね）
├── user_id, tab_id / practice_log_id

Save（保存）
├── user_id, tab_id

Comment（コメント）
├── id, user_id, tab_id / practice_log_id
├── content, created_at

Follow（フォロー）
├── follower_id, following_id
```
